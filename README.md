# 🔐 Smart Security System Using Arduino

## 📌 Project Description
This project is an Arduino-based smart security system created and simulated using Wokwi. It uses electronic components to provide a basic security mechanism.

## 🎯 Objectives
- Develop a simple electronic security system.
- Learn Arduino programming and circuit design.
- Simulate and test the system using Wokwi.

## 🛠️ Components Used
- Arduino Uno
- OLED Display
- Servo Motor
- LEDs
- Push Buttons

## ⚙️ Working Principle
The Arduino processes user inputs and controls the connected components. The OLED displays relevant information, and the servo motor represents the locking mechanism.

## 📁 Project Files
- `sketch.ino` — Arduino source code.
- `diagram.json` — Circuit configuration.
- `libraries.txt` — Required library information, if included.
- `wokwi-project.txt` — Wokwi project configuration, if included.
